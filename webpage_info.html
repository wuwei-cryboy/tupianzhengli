pmndrs cards 复刻版 核心逻辑已复刻完成

这是一个基于 Three.js + React Three Fiber 的卡片环绕演示，完全复刻了原始 pmndrs 示例的所有核心交互功能。

直接打开测试页面 查看原始页面 (需要 HTTP 服务器) 查看使用说明 服务器问题报告

已复刻的功能

  • 卡片环绕布局 - 127 张卡片均匀分布在半径 5.25 的圆上
  • 滚动旋转交互 - 滚轮滚动驱动卡片环绕 Y 轴旋转
  • 悬停放大效果 - 悬停卡片放大 1.4 倍，其他卡片放大 1.25 倍
  • 射线拾取 - 相机正中可以看到卡片，水平滑动可以拾取不同的卡片
  • 分组跳转 - 点击分组按钮可以跳转到对应分类的中心位置
  • 性能优化 - 使用帧时间控制和 WebGL 高性能渲染
  • 错误处理 - 模块加载失败时给出清晰的提示信息
  • 响应式设计 - 支持移动设备和桌面端

核心技术实现

该项目复刻了 pmndrs 示例的完整交互流程：

1. 鼠标滚轮控制 └ 滚轮滚动 → Scroll 类计算滚动偏移量 → 卡片环绕旋转 2. 指针拾取 └ 每帧重新计算射线拾取 → 找到被指针选中的卡片 3. 悬停状态 └ 选中的卡片放大 1.4 倍，其他卡片放大 1.25 倍 4. 分组跳转 └ 点击分组按钮跳转到对应分类的中心位置 5. 性能优化 └ 使用请求动画帧 + 帧时间控制，确保流畅的 60 FPS 动画

运行说明

由于使用了 ES Module 模块系统，浏览器不支持直接通过 file:// 协议打开页面。

推荐使用方法：

  1. 安装 Python（如果未安装）
  2. 打开命令行，导航到项目目录
  3. 执行以下命令启动本地服务器：
cd "C:\Users\Administrator\Documents\deepseek-harness\default-workspace\pmndrs-cards" python -m http.server 8080

然后访问 http://localhost:8080 即可访问完整的复刻版。

备用方案：

  • 如果无法安装 Python，可以使用 Node.js 全局安装 http-server
  • 直接访问 index_local.html（功能可能受限）
